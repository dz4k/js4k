# js4k: three tiny javascript libraries for hypertext applications

**croc**, a tightly packed collection of DOM utilities

**onwhatever**, `on*` attributes for custom events, including an `init` event

**soiree**, a credit-card-sized htmx-like

**instyle**, superpowers for inline styles
